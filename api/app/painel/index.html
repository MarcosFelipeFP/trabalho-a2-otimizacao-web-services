    Histórico de empréstimos de um leitor: filtro por leitor_id, JOIN com o livro e ordenação por data. Sem índice, o banco lê a tabela inteira (Seq Scan) e ainda ordena. Com o índice (leitor_id, data_emprestimo DESC), ele vai direto às linhas do leitor, já na ordem (Index Scan).

    Os testes de carga usam o Grafana k6, que roda num contêiner e não pela página. Abra um terminal na pasta do projeto, rode o comando abaixo e, enquanto o teste roda (cerca de 1 minuto), abra o painel do k6.

    1. Rodar o teste (cache quente, 50 usuários virtuais)

    docker compose run --rm --service-ports -e K6_WEB_DASHBOARD=true k6 run k6/cache.js -e VERSAO=com-cache-quente -e CARGAS=50

    2. Abrir o painel do k6 enquanto o teste roda

    Abrir o painel do k6 (localhost:5665) Só abre durante o teste. Se recusar, use 127.0.0.1:5665.

    Depois desse teste o cache fica cheio: para repetir a demonstração do cache, use “Esvaziar cache” na aba 1.
